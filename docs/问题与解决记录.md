# 问题与解决记录

## 写入说明

每条记录包含问题、处理方法；只记录已确认的事实。

### 模型思考过程无法展示

- **问题**：聊天界面无法展示模型返回的思考内容。
- **处理**：读取 OpenAI 兼容接口的 `reasoning_content` 字段；思考片段写入会话 JSONL，并通过事件回放在聊天界面折叠展示。

### 待办标题无法修改

- **问题**：待办工具缺少修改标题的操作。
- **处理**：新增 `update`，按 ID 修改标题并保留状态；`set_status` 继续负责修改状态。

### Steering 消息可能乱序或进入错误的运行

- **问题**：运行结束与新消息入队并发时，消息可能丢失；消息写入后、应用事件写入前发生失败时，未提交消息可能进入上下文。
- **处理**：在 Session 内串行化入队和终态提交；用 `queue_id` 关联排队消息与应用事件，按 FIFO 应用，仅将已记录 `steer.applied` 的消息纳入上下文。未消费消息保留在原 Run 的事件中。

### 会话写入失败可能产生不确定状态

- **问题**：事件写入、刷新或同步失败时，文件可能留下不完整记录或尚未确认持久化的终态。
- **处理**：写入不确定时拒绝当前进程继续读取该会话并向调用方报告错误；重启恢复时检查记录，未终止的 Run 标记为 `interrupted`。已发生的外部副作用不承诺自动回滚或重试。

### 执行事件字段与关联不完整

- **问题**：排队消息缺少可靠的关联信息；模型响应不完整或流中断时，可用的结束原因和用量无法完整记录。
- **处理**：使用 `queue_id` 关联排队和应用事件，并校验 `message_id` 指向同一 Run 中追加的用户消息；`model.response` 保留可用的结束原因和用量，缺少完整有效消息时使用 `null`。

### JSON 转义绕过工具参数密钥检查

- **问题**：工具参数中的 JSON 转义字符解码后可能还原出已配置密钥，原始参数检查无法识别该内容。
- **处理**：执行前检查原始参数、JSON 解码结果和 Pydantic 参数模型，包括嵌套字段；密钥检查覆盖注册表和待办执行路径。

### 交错文本的流式顺序不一致

- **问题**：模型的 `content` 和 `refusal` 跨 chunk 交错时，文本事件拼接顺序与最终消息不一致。
- **处理**：按最终消息的文本顺序输出归一化片段，对文本和工具片段执行跨片段密钥检查，并检查最终消息。
