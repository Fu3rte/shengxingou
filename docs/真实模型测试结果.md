# 真实模型测试结果

## 验收结果

- 真实模型：19 类场景，每类执行 3 次，共 57 次；54 次通过、3 次未通过，通过率 **94.74%**。
- 失败集中在同一种构造历史边界：总输入达到 75,103 字符，压缩未触发。三次均保留了事实并正常回答，但未满足“触发压缩、缩短上下文”的测试预期。
- 六种工具均由真实模型输出调用；对话追问、工具追问、session/todo 隔离、恢复、删除确认均通过所选案例。
- 存在可压缩旧历史时，真实摘要调用与后续问答通过 3/3；压缩后重新打开 session 的事实追问通过 3/3。
- 同时重新运行本地自动测试：**24 passed，29.17 秒**。

## 量化指标与统计口径

### 正确性

- **场景通过率：54/57 = 94.74%。** 一个案例的所有检查点同时满足才记为通过；压缩失败保留在分母中。
- **工具选择匹配率：57/57 = 100%。** 实际发起工具名称集合与该案例预期集合完全匹配；纯对话预期为空集合。该指标不衡量最优调用次数或任意任务泛化能力。
- **参数 Schema 合法率：42/42 = 100%。** 对全部实际工具调用参数，使用当前注册工具的 Pydantic Schema 重新校验。
- **工具执行完成率：39/39 = 100%。** 共发起 42 次工具调用，其中 3 次删除被按预期拒绝；39 次获得执行授权的调用均有完成结果。
- **计算与计算追问：6/6。** 核对实际工具结果及最终答案中的 391、400。
- **session 交叉污染负向检查：6/6。** 第二个 session 的追问，以及第一个 session 重新打开后的追问，均未输出另一个 session 的项目代号、口令或待办。
- **待办追问更新：3/3。** 更新相同 ID，清单长度保持 1。
- **删除批准/拒绝检查：6/6。** 拒绝后清单不变；批准后当前 session 清空，另一个 session 保持原清单。
- **压缩触发与缩小检查：3/6。** 两组不同历史形状分别执行 3 次；其中一组始终不触发压缩。
- **成功压缩后的摘要关键事实：3/3。** 摘要保留“松岚”和“K9R4”。
- **成功压缩后的回答与重开追问：6/6。** 两条关键事实均可继续回答。
- **终态、唯一终态、trace 的 run ID 关联、测试会话文件不含配置密钥：各 57/57。** 拒绝删除的预期终态是 `stopped`，其余案例是 `completed`。

### 性能

计时从提交用户消息前开始，到读取该 run 的终态事件为止，包含模型、工具和本地持久化时间。各场景串行执行，属于验收耗时测量。

- 单案例总耗时 P50：**4.308 秒**。
- 单案例总耗时 P95：**11.267 秒**。
- 最短：1.311 秒；最长：20.387 秒。
- 57 次案例耗时合计：297.961 秒；不包含场景准备、离线校验与报告整理。
- 首段可见答案文本耗时 P50：**3.261 秒**；P95：**9.312 秒**。

- P50/P95 使用 nearest-rank：对样本排序后取 `ceil(n × p)` 项。

不同案例的模型请求数和工作量不同，这组汇总不用于比较模型性能，也未开展并发压力测试。

## 未通过项的证据与影响

### 压缩边界：达到触发阈值仍无摘要

构造条件：

- 一条约 55,000 字符的旧用户消息，包含项目事实和归档填充。
- 一条旧助手消息。
- 最新用户消息约 15,026 字符。
- 加上系统消息和工具定义，实际模型请求计量为 75,103 字符。

实际结果：

- 三次均正常回答项目事实。
- 三次均无 `compact.request`、`compact.completed`。
- 压缩前后请求计量均为 75,103 字符，缩减率为 0%。

本地代码证据：

- `backend/src/agent/agent_loop.py`：输入达到 72,000 后，只有 `split_recent()` 返回非空旧前缀时才调用摘要。
- `backend/src/agent/compact.py`：保留完整消息组，并至少保留约 16,000 字符的近期内容。最新消息不足该量时，会继续纳入前面的消息组；本例进一步纳入了整条大块旧消息，最终可压缩前缀为空。

影响范围：这说明“达到 72,000 就一定压缩”不成立。该构造下输入接近硬上限时仍可能缺少可压缩前缀；本次未继续验证它越过 80,000 后的真实模型路径。

该用例通过 runtime 直接构造了一条 55,000 字符旧用户消息，超过 HTTP API 单条用户输入 32,000 字符限制。它是底层历史形状的边界测试，尚未证明普通前端输入能直接触发同一情形。

本次只记录观察结果，未修改压缩策略。另一个具有可压缩前缀的历史形状已经完成三次真实摘要与事实追问。
